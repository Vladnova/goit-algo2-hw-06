# Аналіз частоти використання слів у тексті з використанням MapReduce та візуалізацією результатів

## Опис завдання

Цей Python-скрипт завантажує текст із заданої URL-адреси, аналізує частоту використання слів у тексті за допомогою парадигми MapReduce, та візуалізує результати у вигляді графіка топ-слів із найвищою частотою використання.

## Функціональність

1. **Завантаження тексту**:
    - Скрипт отримує текстовий вміст за URL-адресою, використовуючи HTTP-запит.

2. **Обробка тексту**:
    - Застосовується парадигма MapReduce для обчислення частоти використання кожного слова у тексті.

3. **Візуалізація**:
    - За допомогою бібліотеки `matplotlib` створюється графік, що відображає топ-слова з найвищою частотою.

## Покрокова реалізація

1. **Імпорт модулів**:
    - `requests` для завантаження тексту.
    - `matplotlib` для створення графіків.
    - Будь-які інші необхідні модулі для реалізації MapReduce.

2. **Реалізація MapReduce**:
    - Код реалізації MapReduce отримує список слів, обчислює кількість входжень кожного слова (Mapper), та об’єднує результати (Reducer).

3. **Функція для візуалізації**:
    - Створено функцію `visualize_top_words`, яка приймає результати аналізу, будує графік частоти слів і зберігає його як зображення або відображає на екрані.

4. **Основний блок коду**:
    - Завантажує текст за URL.
    - Використовує MapReduce для аналізу частоти слів.
    - Візуалізує топ-слова.
